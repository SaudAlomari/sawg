SAWGAdmin

Connect to GitHub

The admin page saves users and puzzles straight into the repo. It needs a GitHub key, which is saved only on this phone.

  1. Open GitHub → New fine-grained token ↗
  2. Name: sawg admin. Expiration: up to 1 year.
  3. Repository access: Only select repositories → sawg.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Tap Generate token, copy it, and paste it here.

Paste a code

Players send you a sign-up code or a puzzle code. Paste it here.

      Changes show on the site about a minute after saving.
